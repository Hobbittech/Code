
# Digital Diggers — Starter Website

Files included:
- index.html
- about.html
- robot.html
- project.html
- styles.css
- script.js
- assets/ (place images or logo here)

How to use:
1. Download and unzip the folder.
2. Open the folder in VS Code.
3. Edit the HTML files (replace placeholder text) and add images to the `assets/` folder.
4. Open `index.html` in a browser (right-click → Open with Live Server or open file directly).

Colors & theme:
- Neon blue: #00c0ff
- Neon red: #ff1460
You can change them in `styles.css` under :root variables.
