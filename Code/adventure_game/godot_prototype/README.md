# The Unwritten Door — 3D prototype

This is a separate Godot 4 prototype. It leaves the original Python adventure game unchanged.

## Run it

1. Install Godot 4.
2. In Godot's Project Manager, choose **Import** and select this folder's `project.godot`.
3. Press **F6** to run the main scene or **F5** to run the project.

## Controls

- **WASD** — move
- **Mouse** — look around
- **E** — interact with the object under the crosshair
- **Esc** — release the mouse; click the game window to capture it again
- **O / L** — choose open or seal after discovering both clues

## First playable slice

Explore a small 3D writer's study, collect the pencil, book, and key from the desk, use the pencil on the blank wall and the book on its stand, then interact with the door. The choice opens one of two text endings.

The environment currently uses primitive meshes and built-in materials as placeholders; original art, sound, extra rooms, and save/load are not included yet.
